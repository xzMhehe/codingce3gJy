# 家园社区 —— 项目账号与登录地址一览

> 复刻 2008 年腾讯 QQ家园 /  家园社区（2015年6月20日停止运营）。
> 技术栈：MySQL 8 + Gin（Go 1.26）+ GORM + Vue 2.7 + RBAC + 前后端分离。

## 一、系统登录地址

| 系统 | 地址 | 说明 |
|------|------|------|
| 社区首页（广场） | http://127.0.0.1:8080/ | 未登录可浏览，登录后全功能 |
| 登录页 | http://127.0.0.1:8080/#/login | 账号=家园号码（或昵称），登录可用昵称 |

| **管理后台** | http://127.0.0.1:8080/admin-ui/ | **独立管理系统**（单独前端项目 admin-web），用有后台权限的账号登录；主站页脚「管理」也可跳转 |
| 找回资料 | http://127.0.0.1:8080/#/find | 凭昵称查号码 |
| 游戏大厅 | http://127.0.0.1:8080/#/games | 游戏列表 + 各游戏论坛入口 |
| 站内导航 | http://127.0.0.1:8080/#/nav | 全站入口汇总 |
| 聊天室 | http://127.0.0.1:8080/#/chat | 全园公共聊天 |
| API 健康检查 | http://127.0.0.1:8080/api/health | 后端状态 |
| 前端开发模式 | http://localhost:8000 | `cd web && npm run serve`（/api 代理到 8080） |

### 管理后台功能（按权限显示）

登录后进入 `/#/admin`，包含：**社区概览、用户管理**（封禁/重置密码/设角色/设马甲/设身份）、**板块管理**、**帖子管理**（置顶/精华/删帖）、**公告管理**（公告/广播/活动）、**角色权限**、**马甲管理**。
不同角色能看到的标签不同：超级管理员全部可见；管理员除「角色权限/马甲管理」外可见；版主只有概览+帖子管理。

## 四、内置角色与权限（RBAC）

| 角色 | 权限 |
|------|------|
| 超级管理员 | 全部 7 项：后台访问 / 用户管理 / 板块管理 / 帖子管理 / 公告管理 / 角色权限管理 / 马甲管理 |
| 管理员 | 后台访问 / 用户管理 / 板块管理 / 帖子管理 / 公告管理 / 马甲管理 |
| 版主 | 后台访问 / 帖子管理 |
| 普通会员 | 无后台权限（发帖回帖签到聊天等社区功能不受限） |

后台可自建角色、给角色勾权限、给用户换角色，改动即时生效。

## 五、启动方式备忘

```bash
# 一键启动（首次自动构建前端 + 建表 + 种子数据）
qqjiayuan\start.bat

# 手动启动后端（需先 build 前端）
cd server && go run .            # http://127.0.0.1:8080

# 前端构建 / 开发
cd web && npm run build          # 产物 dist，由后端托管
cd web && npm run serve          # 开发热更新 http://localhost:8000
```

首次启动自动建表并写入种子数据（板块、角色权限、公告、示例帖子）。数据库连接在 `server/config.yaml` 修改。
