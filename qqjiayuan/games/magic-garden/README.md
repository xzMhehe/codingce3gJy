# 魔法花园 · 独立前后端

魔法花园是一个**可以独立运行**的前后端小应用，也能作为  家园社区的**一个游戏模块内嵌**。

## 一、单独拿出来运行（不依赖主站）

只安装 Go，无需 Node、无需 MySQL：

```bash
cd games/magic-garden/server
go run main.go
```

浏览器打开 **http://localhost:8090** 即可游玩（种植→生长→收获，赚金币）。

- 后端：标准库实现（仅 `net/http` + `encoding/json`），零第三方依赖
- 数据：内存存储（按昵称隔离），重启信息清空，方便体验
- 前端：独立的 `web/index.html`（原生 JS，参考站 WAP 风格）

改端口：`set PORT=8000 && go run main.go`

## 二、内嵌进主站（qqjiayuan）★ 完整版

主站内的魔法花园是**另一套完整版**（GORM + MySQL 持久化 + Vue 游戏页），玩法对齐诺哈三代 ASP 版：

- 后端：`server/internal/model/garden.go` + `server/internal/handler/garden.go`
- 接口：`/api/games/garden/{view|visit|shop|buy|sow|care|harvest|pick|addland|basket|bottle|gift|giftlog|room|mix|map|setting|msgs}`
- 前端：`web/src/views/Garden.vue`（路由 `/#/games/garden`）
- 入口：游戏大厅 `web/src/views/Games.vue` 里的「魔法花园」
- 素材：`web/public/static/picture/garden/`（从诺哈三代破解版 `data/game/garden` 复制，种子 s_s_* / 图鉴 m_s_* 等 1730 张）

### 完整版玩法（对齐诺哈三代 ASP 版 wap_garden）

| 玩法 | 说明 |
|------|------|
| 花园 | 每个用户一座（昵称的花园），花园等级 1-35 级称号（见习魔法学徒→…→传说魔法师），每级 200 经验 |
| 花圃 | 初始 2 块，可添置至 10 块（需等级+G币，费用递增） |
| 种子 | 商店 9 种普通种子（按花园等级解锁购买）+ 魔法屋合成 6 种特殊种子 |
| 生长 | 种子期→花苗期→花蕾期→开花 四阶段，各阶段后半段分别可浇水/锄草/捉虫（各+1经验） |
| 开花 | 时长到自动变出一朵图鉴花（普通/独特/珍稀），产量=随机(less,more)±打理修正（最低1） |
| 收获 | 花进花篮，金币 random(0,产量)，首次点亮图鉴+10（普通）/+100（独特·珍稀），已有+1 |
| 采摘 | 好友可来采摘成熟花（每花圃每人限1次，剩≥2朵才能摘），园主可设采摘权限（所有人/仅好友/禁止） |
| 花篮/花瓶 | 收获的花进花篮，好友送的花进花瓶 |
| 送花 | 花篮→选好友→送花（带留言），对方花瓶+1，花园消息通知 |
| 魔法屋 | 消耗花篮花朵→合成特殊种子（经验+20），种出独特/珍稀花 |
| 图鉴 | 花之图谱 33 种，分普通/独特/珍稀三档，点亮进度展示 |
| 消息 | 浇水/锄草/捉虫/采摘/送花/收获 都会留花园消息，7 天自动清理 |

### 花园数据管理（管理端）

种子 / 图鉴 / 合成配方 / 精灵花册全部存入数据库（`garden_seeds` / `garden_maps` / `garden_mixes` / `garden_elves`），
管理后台侧边栏「**魔法花园**」（与空间管理平级）可增删改查，保存即时生效（无需重启）：

- **花园活动**：活动标题/说明/上架
- **花园花种**：名称/类型（普通·特殊）/所需等级/价格/三阶段生长分钟/产量范围/花语/上下架
- **花之图谱**：花名/所属种子/稀有度（普通·独特·珍稀）/图片文件（默认按 ID 取 `m_s_X.gif`，可自定义）
- **合成配方**：产物种子 ← 材料花 × 数量
- **精灵花册**：10 只花园精灵（名称/介绍/图片/解锁需点亮图谱数），点亮图谱数达标自动唤醒

> 图片采用**静态路径**方案：表里存文件名（如 `m_s_12.gif`），文件放
> `web/public/static/picture/garden/`，前端按 `文件名` 拼接访问；缺图时按 `m_s_<ID>.gif` / `elf_<ID>.gif` 兜底。
> 数据表为空时自动回退内置默认配置（与 seed 初始数据一致），保证老库/新库都能跑。

用户端花园页（`/#/games/garden`）导航：花园/好友/花房/魔法屋/活动 + 底部 背包/商店/排行/帮助/论坛 全部可点：
- **排行**：花园等级经验 TOP20（`/api/games/garden/rank`）
- **帮助**：对齐 ASP help_info 的 13 条玩法问答
- **论坛**：跳转家族论坛 / 社区广场
- **精灵花册**：已唤醒 X/10 展示（`/api/games/garden/elves`）

主站版与独立版玩法一致，数据各自独立，可按需选用。
