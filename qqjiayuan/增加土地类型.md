# 增加土地类型

本文记录二战风云（ezfy）新增土地类型的规则、代码改动点和上线步骤。以后再加新地形，按本文末尾的清单走一遍即可。

## 2026-10-20：新增海野「渔场」「矿礁」

### 为什么加

原来海野的采集产出只有：

| 地形 | 产出 |
|---|---|
| 岛屿(7) | 钢铁 |
| 海底森林(海洋 8 + 有野地) | 石油 |

玩家反馈海野缺**粮食**和**稀矿**，因此新增两种海野细分地形：

| 地形 id | 名称 | 类别 | 采集产出 | 守军/出征口径 | 宝物池 |
|---|---|---|---|---|---|
| 10 | 渔场 | 海野 | 粮食 | 海野（wild_type=2、海军可出征） | 玛瑙项坠 / 翡翠项链 / 祖母绿 |
| 11 | 矿礁 | 海野 | 稀矿 | 海野（wild_type=2、海军可出征） | 黑曜石戒指 / 琥珀项链 / 铂金戒指 |

### 生成规则

- 只有**基础地形是海洋(8)、且该格有野地（`ezfyWildlandLevel > 0`）**时才会细分。
- 纯海洋（野地等级 0）仍然是「海洋」，不会变成渔场/矿礁。
- 海洋野地按坐标哈希分配，约：
  - **40% 渔场**（粮食）
  - **30% 矿礁**（稀矿）
  - **30% 海底森林**（石油，保持原类型）
- 岛屿(7) 保持原样：海野玩法、钢铁产出，不参与这次细分。
- 地形是坐标哈希推导的，**不需要改数据库、不需要刷数据**；部署新二进制后立即生效。
- 管理端「地图格子覆盖」仍可手动把某格强制成 10/11（或改回 8），覆盖优先于哈希。

### 上线后验证

1. 地图上找海洋野地，应能看到「渔场」「矿礁」「海底森林」三种名称。
2. 点开渔场详情：
   - 地形显示「渔场」
   - 采集可获得「粮食」
   - 守军预览是海军兵种（驱逐舰/潜艇/战列舰/航母）
3. 点开矿礁详情：
   - 地形显示「矿礁」
   - 采集可获得「稀矿」
4. 派海军出征渔场/矿礁，不应再提示「只能出征岛屿/海底森林/沿海平原」。
5. 管理端「地图 → 地图格子覆盖」的地形下拉应出现「渔场」「矿礁」。

### 调整产出比例

比例只由 `ezfySeaWildTerrain` 里的取模分支控制：

```go
h := ezfyAbs(x*7919 ^ y*104729)
switch h % 10 {
case 0, 1, 2, 3: // 40% 渔场
case 4, 5, 6:    // 30% 矿礁
default:         // 30% 海底森林
}
```

想改成「渔场 30% / 矿礁 20% / 海底森林 50%」，把分支改成 `0,1,2`、`3,4`、其余即可。改完重新打包部署两个区。

## 以后新增土地类型的通用清单

1. **定 id 和名称**：接着现有最大 id 往后排，更新 `ezfyTerrainNames`。
2. **定玩法类别**：陆地野地 / 海野 / 沿海平原 / 城市专用。海野要加进 `ezfyIsSeaWildTerrain`。
3. **定采集产出**：更新 `ezfyGatherResName`；需要宝物就更新 `ezfyTerrainTreasureNames`。
4. **定生成方式**：
   - 纯展示/管理端手动画：只加 id 和名称；
   - 按坐标自然生成：在 `ezfyTerrainEx` 或类似函数里写确定性哈希，**不要**引入随机数，否则每次请求地形会变。
5. **检查出征限制**：海军/空军等兵种限制函数（如 `ezfyNavalTargetAllowed`）是否要纳入新地形。
6. **检查地图展示**：`MapView` 的分支顺序、纯海洋守卫、精英寇城扫描、前端地图格文案/底色。
7. **管理端**：格子覆盖下拉、校验范围、列表展示。
8. **补测试**：展示名、采集资源、海野判定、宝物池、管理端校验。
9. **打包部署**：1 区 + 2 区都要部署；纯哈希地形不需要 SQL。
10. **更新本文**：记录日期、id、名称、产出、生成比例、验证结果。

## 回滚

- 代码回滚：重新部署上一版 `WWIIbushu.tar.gz` 即可。
- 如果只是不想让某格出现新地形：管理端「地图格子覆盖」把该格强制回 8（海洋）或其它地形，覆盖优先于哈希。
- 不需要回滚数据库：地形没有落库，`ezfy_map_tile` 只有管理端手动覆盖的行。
