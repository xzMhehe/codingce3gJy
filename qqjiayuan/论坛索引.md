# 论坛索引（家园）

> 家园论坛高频查询的复合索引。帖子列表（按版块）、我的帖子/回复计数/列表都带 `status` 过滤，
> `threads`/`replies` 只有单列外键索引（`board_id`/`user_id`/`thread_id`），补带 `status` 的复合索引直接命中。
> 表名为 GORM 默认复数：`thread`→`threads`、`reply`→`replies`。
> GORM AutoMigrate 只保证补列/主键，普通复合索引需显式执行下面的 `ALTER`。

## threads — 帖子表

版块主页帖子列表按 `board_id + status + audit_status` 过滤：

```sql
ALTER TABLE threads
  ADD INDEX idx_thread_board_status (board_id, status, audit_status);
```

「我的帖子」计数/列表按 `user_id + status` 过滤：

```sql
ALTER TABLE threads
  ADD INDEX idx_thread_user_status (user_id, status);
```

## replies — 回复表

帖子回复楼层/总数按 `thread_id + status` 过滤：

```sql
ALTER TABLE replies
  ADD INDEX idx_reply_thread_status (thread_id, status);
```

「我的回复」计数/列表（福利、个人页）按 `user_id + status` 过滤：

```sql
ALTER TABLE replies
  ADD INDEX idx_reply_user_status (user_id, status);
```

## 幂等性

以上 `ALTER ... ADD INDEX` 若索引已存在会报 `Duplicate key name`，重复执行无害；已按
`information_schema.STATISTICS` 判存在再建（见 `seed/ezfy.go ensureEzfyIndex`），部署新二进制会自动建。
