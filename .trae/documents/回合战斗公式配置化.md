# 回合战斗公式数值配置化（挪进「二战系统配置」）

## Context

回合战斗引擎 [ezfy_battle.go](file:///Users/mxz/mxz-code/github/codingce3gJy/qqjiayuan/server/internal/handler/ezfy/ezfy_battle.go#L19-L40) 顶部有 5 个**硬编码机制常量**（最大回合数、战场距离、后退上限、暴击基础加成、驻军溃败阈值）。兵种攻防数值已由 `ezfy_cfg_troop` 配置化，但这 5 个战斗机制参数仍写死在代码里，调整需要改代码+重新部署。

项目已有成熟的「二战系统配置」机制（`ezfy_cfg_limit` 表 + 管理端系统配置页 + `ezfyCfg.limit.Xxx` 全局读取 + 保存即 `cfgsReload()` 热更新），代码注释里也写明"后续如需可调，可挪进二战系统配置"。

目标：把这 5 个常量挪进 `ezfy_cfg_limit`，管理端页面可改、保存后**立即生效无需重启**。

## 新增配置项（默认值 = 现硬编码值）

| 配置项 | JSON key | 默认值 | 含义 | 校验范围 |
|---|---|---|---|---|
| 最大回合数 | `battle_max_rounds` | 40 | 战斗最多回合，平局上限 | 1~200 |
| 战场初始距离 | `battle_start_dist` | 6000 | 攻守方相距初始距离 | 1000~50000 |
| 最大后退距离 | `battle_retreat_max` | 10000 | 双方各自最多后退 | 1000~100000 |
| 暴击基础伤害加成% | `crit_base_bonus_pct` | 50 | 装备无 crit_dmg 时兜底倍率 | 1~500 |
| 盟军驻军溃败撤退阈值% | `garrison_break_pct` | 50 | 守方兵力跌破此比例判败 | 1~100 |

## 改动链路（照抄现有配置项的五环）

1. **Model** — [internal/model/ezfy.go](file:///Users/mxz/mxz-code/github/codingce3gJy/qqjiayuan/server/internal/model/ezfy.go#L276-L355) `EzfyCfgLimit` 结构体加 5 个 `int` 字段（`gorm` 默认值 + `json` tag + 中文注释），风格对齐相邻字段（如 `DispatchPeriodH`）。
2. **数据库种子/迁移** — [internal/seed/seed.go](file:///Users/mxz/mxz-code/github/codingce3gJy/qqjiayuan/server/internal/seed/seed.go#L168-L205) 按既有模式：`ALTER TABLE ezfy_cfg_limit ADD COLUMN ...` + `UPDATE ... SET ... WHERE ... IS NULL` 回填默认值（老库启动自动迁移）。
3. **管理端接口** — [internal/handler/ezfy/ezfy_admin_round9.go](file:///Users/mxz/mxz-code/github/codingce3gJy/qqjiayuan/server/internal/handler/ezfy/ezfy_admin_round9.go#L25-L80) GET 初始化默认值；保存接口（同文件 L701-L934 区间）按现有校验风格加 5 项的取值/范围校验与落库；复用 L1111 的 `cfgsReload()` 热更新（已生效）。
4. **管理端前端** — [admin-web/src/components/admin/AdminEzfyBuildLimit.vue](file:///Users/mxz/mxz-code/github/codingce3gJy/admin-web/src/components/admin/AdminEzfyBuildLimit.vue) 新增一组「回合战斗公式」数字输入框（照抄现有表单项写法，如「单城兵力上限」），随表单一起保存。
5. **战斗引擎读取** — [ezfy_battle.go](file:///Users/mxz/mxz-code/github/codingce3gJy/qqjiayuan/server/internal/handler/ezfy/ezfy_battle.go#L19-L40) 顶部 const 区改为包内读取 `ezfyCfg.limit.Xxx`，用 `ezfyLimitOr(值, 默认值)`（helper 在 [ezfy_geo.go](file:///Users/mxz/mxz-code/github/codingce3gJy/qqjiayuan/server/internal/handler/ezfy/ezfy_geo.go)）兜底零值；5 个使用点（最大回合数、进退边界等，含 L991-L1004 前进/后退边界）同步替换。
