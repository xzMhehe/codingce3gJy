# 风云榜（PVP 周榜）积分获取规则

> 二战风云 玩家对战周榜。按**自然周**（周一 00:00 ~ 周日 23:59，周串形如 `20261012-20261018`）统计**玩家 vs 玩家**（PVP）战斗，按**积分**排名。
>
> 规则版本：2026-10-14（含杀敌分、防刷三项）。代码实现：`server/internal/handler/ezfy/ezfy_pvp_rank.go`、`server/internal/handler/ezfy/ezfy_order.go`（唯一结算点累积）。

---

## 一、计入 PVP 的战斗范围

- ✅ 攻打**玩家城市**（target_type=3）的 掠夺 / 征服 / 战斗，攻守双方都记
- ❌ 野地、寇城、活动目标、NPC、集结守方等**一律不计** PVP
- 战斗结算时按 `(周串, 玩家ID)` 唯一键累加；昵称/军团为写榜时刻快照

## 二、单场积分公式

```
单场积分 = (行动分 + 胜负分) × 兵力劣势系数 + 杀敌分 + 战损比分
```

单场**上限 400**（防刷）。

### 1. 行动分

| 行为 | 分值 |
|---|---|
| 进攻（掠夺 / 征服） | **20** |
| 防守 | **15** |

### 2. 胜负分

| 结果 | 分值 |
|---|---|
| 胜 | **40** |
| 平 | **15** |
| 负 | **10**（参战即给，鼓励对抗） |

### 3. 兵力劣势系数（以少打多奖励）

```
系数 = min(3.0, 对方兵力 ÷ 己方兵力)，己方兵力 ≥ 对方时为 1.0
```

- 谁的兵力劣势谁享受加成，攻守双方都生效
- **攻方出征兵力少、守方兵力多时，攻击方按劣势比例多拿分**（最高 3 倍）
- 例：守方 1 亿兵 vs 攻方 1000 万兵 → 攻方系数 = 3.0

### 4. 杀敌分（按灭敌绝对量计）

```
杀敌分 = min(200, 20 × log10(灭敌))，灭敌 0 不给分
```

- 让**大仗有分量**：灭敌量级越大分越多（千万级 ≈ 133~140 分，百万级 ≈ 120 分，10 万 ≈ 100 分，1 万 ≈ 80 分）
- 对数压缩：灭敌翻 10 倍只多 20 分，不会被天文数字刷爆

### 5. 战损比分（战损比 = 灭敌 ÷ 战损）

```
战损比奖励 = min(30, 战损比 × 10)；战损 = 0 时按满 30 给
```

| 战损比 | 奖励 |
|---|---|
| ≥ 3（无损或大胜） | 30（满） |
| 1 | 10 |
| < 1 | 小于 10（越亏越少） |

## 三、防刷规则（★ 2026-10-14）

上线后发现 1 兵刷 / 小号互刷，加三条防刷：

| 刷法 | 对策 |
|---|---|
| **1 兵碰瓷**（1 兵来回送白拿行动/胜负分，或小号送人头给大号刷防御分） | 本场**攻方**投入兵力 < 1000 → **攻守双方本场都计 0 分** |
| **防守方 1 兵挂分** | 守方自己投入兵力 < 1000 → 守方 0 分 |
| **空城刷**（打零兵力空城） | 守方投入兵力 = 0 → 进攻方 0 分 |
| **小号互刷**（同两个号反复对打） | 同一自然周内与**同一对手**的积分累计封顶 **8000**；达上限后再打：场次/灭敌/战损照记，积分不再计入 |

> 兵力指**本场实际投入**（损失 + 剩余）；攻方为撤退/战损部队，守方为城市守军 + 驻军聚合。

## 四、计算示例（真实战报）

攻方「邪恶大本营」掠夺守方「再战辉煌基地」，平局。
攻方投入 1020 万（航母），守方投入 1.03 亿（步兵 2 / 摩托化骑兵 39 / 轰炸机 297 万 / 驱逐舰 15 / 航母 9990 万）。
攻方灭敌 461.6 万、战损 898.2 万。

| 分项 | 攻方 | 守方 |
|---|---|---|
| 行动分 | 20（进攻） | 15（防守） |
| 胜负分 | 15（平） | 15（平） |
| 兵力劣势系数 | 3.0（1.03亿÷1020万，封顶） | 1.0 |
| 杀敌分 | 20×log10(461.6万) ≈ **133** | 20×log10(898.2万) ≈ **139** |
| 战损比分 | 0.51×10 = 5 | 1.95×10 = 19 |
| **单场合计** | **243** | **188** |

## 五、补充说明

- **周边界**：战斗结算时间落进哪一周记哪一周，跨周各自累计
- **平局**：双方都不算胜（胜场 +0），胜负分按平 15 计
- **同对手封顶 8000** 可按运营需要调整（常量 `ezfyPvpFoeCap`）
- 榜单排名关键词：`points DESC, kills DESC, wins DESC, losses ASC`
- 管理端「风云榜」模块可查任意周；玩家端通行榜页「风云榜」tab
