# 二战征途 · 以少胜多方案

> 生成日期：2026-10-12
> 用途：解决「攻方携带兵力有限、守方兵力多，弱方必输」的问题，参考主流 SLG（列王的纷争 CoK / 万国觉醒 RoK / Evony / 部落冲突 CoC / GOW）的以少胜多机制。

---

## 一、现状诊断（为什么会必输）

以玩家战报为例：

```
[败] 攻方：战列舰 513万 → 0（全灭）  航母 496万 → 0（全灭）
[胜] 守方：火箭 316万 → 0
           战列舰 2632万 → 2598万（-34万）  航母 5160万 → 5156万（-4万）
```

**核心问题：当前战斗是纯对耗（attrition）模型。**

1. **胜负判定 = 一方全灭**：战斗引擎最多 40 回合（30 秒/回合），只有一方兵力归零才结束。守方 8000 万兵力，攻方就算每回合稳定啃掉 40 万，40 回合最多啃 1600 万，永远啃不完 → 必然失败。
2. **攻防同口径对杀**：我打你多少伤害，你大致打回我多少；双方伤害都正比于各自兵力，兵力多的一方每回合造成的伤害也大，形成「我死得快 + 你死得慢」的双重劣势。
3. **没有「打崩」机制**：不存在士气/溃败/接战上限这类能让弱方「一波带走」的判定，弱方只能慢慢被耗死。
4. **军官乘区尚在**：150 级 vs 350 级，军官属性加成确实有差距，但只放大伤害百分比，无法扭转数量级劣势。

> 结论：要让「以少胜多」成立，必须在**胜负判定**和**伤害分配**层面引入新机制，而不是继续调数值。

---

## 二、主流 SLG 的以少胜多机制（总览）

| 机制 | 一句话原理 | 代表游戏 | 对当前引擎改动量 |
|---|---|---|---|
| 兵种克制 | 用对兵种，等效战力 ×1.5~3 | CoK / Evony | 小（配表 + 伤害乘区） |
| 士气/溃败判定 | 损失超阈值 → 一方崩盘判负，残兵溃逃 | 三国志战略版 / 万国觉醒 | 小（回合末判定 + 胜负改写） |
| 接战上限 + 集火 | 海量守军不能同时开火，且可逐个击穿 | CoK / CoC | 中（每回合锁定目标数 + 伤害集中） |
| 练度乘区（精英碾压） | 高阶军官/星级/高级兵给成倍乘区 | RoK / Evony | 中（已有基础，需强化与平衡） |
| 先手/奇袭 | 攻方先手一轮或不触发防御设施 | CoK（侦查判定） | 小（回合 0 加一轮先手） |
| 战损不对称 | 守方战死多、攻方多为轻伤回营 | CoK / RoK | 中（胜/败战损系数） |

## 三、各机制详解与落地建议

### 方案 1：兵种克制表（counter） —— 推荐优先

**原理**：指定兵种对特定兵种有额外伤害倍率（如 ×1.5~×3）。数量不足时只要兵种选对，等效战力直接翻倍。

**适配当前引擎**：`ezfyCfgTroop` 增加 `counter_troop_id`（克制目标）+ `counter_mult`（倍率）两列，战斗结算伤害时命中克制的目标 ×倍率。战报里守方是「战列舰+航母+火箭+防空炮」，若我方带「驱逐舰（克制战列舰）+潜艇（克制航母）」这类对海主力，就能用几百万打出千万级效果。

**数值示例**：
```
驱逐舰 vs 战列舰：伤害 ×2.0
潜艇   vs 航母：  伤害 ×2.0
防空炮 vs 空军：  伤害 ×1.5
火箭   vs 陆军：  伤害 ×1.8
```

**改动量**：小。管理端兵种配置页 + 战斗引擎伤害处接一个倍率查询即可。
**平衡风险**：克制表全开会让「最强兵种」被针对；建议克制倍率封顶 ×2，且高级兵被克制只到 ×1.3。

---

### 方案 2：士气 / 溃败判定（rout） —— 推荐优先，最直接

**原理**：战斗不以「全灭」为唯一终局。每回合末按损失比例判定士气：
- 本回合**战损 ≥ 本军剩余兵力一定比例**（如 8%）→ 士气下降；
- 士气跌破阈值（或累积战损比例超过 50%）→ 判负，剩余兵力溃逃（按比例折损回城/返回出发城）。

**为什么它能以少胜多**：弱方只要能保证「每回合自己掉得少、对方掉得相对多」，就能在对方还剩大量兵力时**一波打崩判胜**——对应战报里守方每回合掉 40 万/8000 万 = 0.5% 的现状，只要我方高战力压低对方战损比，50 回合上限内（可把 40 回合上限放开到 60）就能触发溃败。

**适配当前引擎**：在 `ezfyBattleTick` 每回合结算后增加士气判定（读双方战损快照），把 `Win` 从「全灭」扩展出「溃败」分支；溃败方剩余兵按比例退回，战报写「XX 军士气崩溃，剩余部队溃逃」。

**数值示例**：
```
士气 100 起步；每回合己方战损 > 剩余兵力的 10% → -25 士气；
士气 ≤ 30 或 累计战损 > 55% → 溃败判负。
守方每回合被啃 40万/8000万 = 0.5% → 士气不动；
攻方如果能每回合稳定造成 守方总兵力 10%+ 的伤害 → 4 回合内打崩对方。
```

**改动量**：小到中。核心是一个判定函数 + 胜负/战报改写 + 兵力回退逻辑。
**平衡风险**：太激进会变成「谁先手谁赢」。建议溃败判定只在「双方战力比 > 2:1」时生效（弱方打崩强方只允许发生在输出效率真实碾压时）。

---

### 方案 3：接战上限 + 集火（engage cap & focus fire）

**原理**：
- **接战上限**：每回合每个单位只能锁定有限目标，海量守军不是所有单位同时开火，而是受「前线容量」限制——这天然降低守方海量优势。
- **集火**：伤害不是均匀摊到对方所有单位，而是优先集中到「当前锁定目标」，让精英单位能逐个击穿对方核心兵种，而不是每回合把伤害洒在几十亿总血量上。

**适配当前引擎**：每回合结算时，双方各取「接战上限 N 个目标」（按前排顺序），伤害只在锁定目标间分配；非接战单位本回合不输出。
**数值示例**：接战上限 = 每方 20 个单位；守方 100 个单位中只有 20 个能打到我方 → 我方每回合受击面大幅缩小。

**改动量**：中。要动伤害分配循环。
**平衡风险**：接战上限过小会变成「填人数无用」，过大无效。建议按双方总兵力比例动态调整（人多时上限略高但仍有封顶）。

---

### 方案 4：练度乘区强化（精英碾压）

**原理**：军官等级/星级/高级兵种/装备给的加成从「加法」提升到「乘法乘区」，一个高练精英可以顶几十万杂兵。这是 RoK/Evony 里「一队精英打散一群」的主要来源。

**现状**：当前引擎已有军官属性加成乘区（150 vs 350 级差距客观存在），但还没有「星级压制」「兵种等级压制」这类非线性乘区。
**落地建议**（按效果从大到小）：
1. 军官星级压制：星级差每 1 星，对低星方伤害 +8% 且受伤 -8%（封顶 40%）；
2. 高级兵种系数：把 cfg 的 attack/defense 按「等级梯次」设计，顶级兵 base 攻击 = 中级 ×2；
3. 士气联动：高士气方伤害 +10~20%。

**改动量**：中。乘区都是现成的地方接一下。
**平衡风险**：练度碾压过度 = 「满级玩家无敌」，需配合兵种克制相互制衡。

---

### 方案 5：先手 / 奇袭（surprise）

**原理**：进攻方享受「奇袭」：若目标城市防守方未在线/未设置防御指令，进攻方先手一回合，且不触发城墙/陷阱部分减伤。信息优势 → 弱方以小博大。

**适配**：侦察命令（已有侦察机）后发起的进攻标记「已侦察」，攻方第一回合先手。
**改动量**：小。
**平衡风险**：会鼓励「侦察→偷袭」循环，需配合侦察消耗/冷却。

---

### 方案 6：战损不对称（casualty asymmetry）

**原理**：守方（被攻打）战死比例更高，攻方多为轻伤、大部分兵力回营。让弱方「敢打」，输了损失可控。

**适配**：胜/败结算时对攻方剩余兵力按「溃退系数」（如 60% 存活回城）处理；守方阵亡全额。
**改动量**：中。
**平衡风险**：会明显加速资源流动（进攻频繁），需搭配野地/城市收益规则。

## 四、推荐落地组合（按改动量从小到大）

| 阶段 | 组合 | 效果 | 改动量 |
|---|---|---|---|
| **第一步** | 兵种克制表 + 士气溃败判定 | 以少胜多的地基：选对兵种等效翻倍 + 效率碾压可打崩 | 小~中 |
| **第二步** | 接战上限 + 集火 | 海量守军优势受限，精英可逐个击穿 | 中 |
| **第三步** | 练度乘区强化 + 战损不对称 | 成长驱动 + 鼓励进攻 | 中 |

---

## 五、落地前的平衡检查清单

1. **克制表封顶**：克制倍率 ≤ ×2，高级兵被克 ≤ ×1.3，避免一兵种通吃。
2. **溃败只奖励真实碾压**：战力比 < 2:1 时溃败阈值调低（不容易崩），防止势均力敌时拼先手。
3. **海量仍要有意义**：接战上限要动态，不能让「堆兵」彻底无用（守城仍应有海量优势）。
4. **战报透明度**：新机制要在战报里明示（「士气崩溃」「克制加成×2」「奇袭先手」），否则玩家觉得是玄学。
5. **与现有规则的耦合**：采集/掠夺/驻守战斗共用同一引擎，新判定对非玩家战斗（野地、活动、掠夺）要确认不破坏既有产出曲线。

---

## 六、小结

- **必输的根源**是「全灭制 + 同口径对耗」，数值调多少都救不回来；
- 主流游戏的答案组合是 **克制 + 溃败 + 接战上限**，练度/奇袭/战损作为放大与润滑；
- 建议按「第一步 → 第二步 → 第三步」分阶段落地，每步单独验证平衡再上线。
