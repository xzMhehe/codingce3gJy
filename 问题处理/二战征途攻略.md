# 二战征途游戏攻略

> 本攻略基于当前线上版本的真实机制整理，覆盖建筑、造兵、打野地、起分、采集、玩家战争、军团战争七大模块。

---

## 一、建筑

每个城市内有 21 种建筑，分为四类：

### 1. 资源建筑（提高产量）
| 建筑 | 作用 |
|---|---|
| 农田 | 生产粮食 |
| 炼钢厂 | 生产钢铁 |
| 石油基地 | 生产石油 |
| 稀矿厂 | 生产稀矿 |

资源产量可被「种植/炼钢/勘探/冶炼技术」科技加成（每级 +10%）。

### 2. 军事建筑（造兵与防御）
| 建筑 | 作用 |
|---|---|
| 军工厂 | 生产陆军（步兵/坦克/卡车/装甲车/突击炮/火箭等） |
| 轻工厂 / 重工厂 | 生产现代化部队装备设施 |
| 停机坪 | 生产航空部队（侦察机/歼击机/轰炸机/特种兵） |
| 航海协会 | 生产海军（驱逐舰/潜艇/战列舰/航母），**只能在沿海城市建造** |
| 围墙 | 城市防御主导，可建造碉堡等防御设施 |
| 运输站 | 提高部队行动速度 |
| 雷达站 | 对敌军入侵进行预警 |

### 3. 功能建筑（发展与管理）
| 建筑 | 作用 |
|---|---|
| 市政厅 | 城市生产、建筑、经济、文化综合性中心 |
| 民居 | 提供人口上限 |
| 科研中心 | 研究城市各方面科技 |
| 军校 | 军官培训，可挑选军官 |
| 参谋部 | 军官居住、办公，进行城守任命 |
| 交易所 | 进行资源交易 |
| 仓库 | 储存资源，保护资源不被抢夺 |
| 司令部 | 军队出征指挥中心 |
| 联络中心 | 允许盟友驻军 |

### 4. 发展建议
- **前期**：优先升资源建筑（农田/炼钢厂/石油基地/稀矿厂）保证产量，同时升市政厅、民居（人口上限）、科研中心（科技前置）。
- **中期**：司令部（出征指挥）→ 军工厂（造兵）→ 围墙（城防）。开始打架前务必把城墙等级拉起来。
- **后期**：科研中心全力点军事科技（军训艺术/武器科技/装甲科技/弹道学等）。
- 建筑可进入「建造中队列数」管理建造/升级队列，满足条件可一键升至 9 级，省去逐级点的时间。

## 二、造兵

### 1. 兵种一览（20 种）
- **陆军**（军工厂）：步兵、摩托化骑兵、卡车（运输/负重 1200，运粮运资源）、装甲车、轻型坦克、重型坦克、突击炮（射程 1500）、火箭（射程 3300 远程火力）
- **空军**（停机坪）：侦察机（速度极快 5000）、歼击机、轰炸机、特种兵（对地/对空高攻）
- **海军**（航海协会，需沿海城市）：驱逐舰、潜艇（对海 92 极强）、战列舰（1500 血大肉盾）、航母（2200 血、负重 10000，远程 3100）
- **城防**（围墙建造）：碉堡（300 血肉盾）、榴弹炮（射程 5300）、反坦克炮（射程 5200）、防空炮（对空 70 高）

每个兵种有独立的：生命、**对海/对陆/对空攻击**、防御、速度、射程、负重、人口、耗粮。

## 三、打野地

### 1. 野地类型与等级
- **陆地野地**（type 1）：0~10 级，守军为陆军/装甲/火炮
- **海野**（type 2）：0~10 级，守军为空军/海军，**需用海军/空军去打**
- **寇城**（type 3）：0~10 级，守军数量庞大、奖励最高（资源 10 万~250 万）

> **注意**：下面所有守军兵力、战利品均为**最终生效数值**——守军已乘「野地兵力倍率 ×10」，战利品已乘「野地资源倍率 ×10」（管理端「二战系统配置」可调）。

### 2. 守军兵力与打野配置参考

| 野地等级 | 守军强度（乘倍率后） | 建议兵力 |
|---|---|---|
| 陆地 1~2 | 1万~5万 | 2~5万 |
| 陆地 3~4 | 5万~12万 | 10~15万 |
| 陆地 5~6 | 2万~13万（装甲/坦克为主） | 20~40万 |
| 陆地 7~9 | 5万~40万（含突击炮/火箭/空军） | 50~200万 |
| 陆地 10 | 80万~250万 | 300万+ |
| 海野 1~3 | 5万~15万（歼击机/驱逐舰） | 5~20万海军 |

> 打不过就补兵/换克制兵种，不要硬莽高级野地。

### 3. 出征配置建议
- 开图：侦察机（速度快）探路 + 低消耗部队清低级野地
- 打高级野地/寇城：带克制兵种 + 高统帅军官，主力一波
- 打海野：**别带纯陆军**，用海军（驱逐舰/战列舰）或空军

### 4. 征服 vs 掠夺
- **征服**：占领该野地 → 成为自己的附属野地（可用于后续**起分建城**、采集）
- **掠夺**：只抢资源，不占领
- **注意**：正在采集中的野地不允许征服/掠夺操作，需等采集结束。

### 5. 战利品（最终数值）
- **资源**：野地/寇城战斗胜利后，在配置范围内随机一个值、然后**乘资源倍率 ×10**，粮/钢/油/稀/金**各给一份**：
  - 陆地野地 1~2 级：约 1 万~4 万（每项）
  - 陆地野地 5~6 级：约 5 万~7 万（每项）
  - 陆地野地 10 级：约 11 万~12 万（每项）
  - 寇城 10 级：约 120 万~250 万（每项）
- **装备**：低级（青铜军刀/步枪M1903）→ 高级（狙击步枪/合金装甲）→ 顶级（元帅权杖/元帅礼服/帝国勋章），有独立掉落概率
- **珠宝**：黄金手镯/玛瑙项坠/红宝石戒指/蓝宝石戒指/祖母绿等，可用于军衔晋升

### 6. 活动野地
活动野地/活动寇城有特殊/高级/中级散件掉落（概率见代码常量配置），胜利后还会按配置**必掉宝物**（珠宝），并记录进背包、战报和系统播报。

## 四、起分（建造新城/分城）

### 1. 起分条件（全部满足）
1. **地形**：目标坐标必须是「平原」或「沿海平原」（沿海平原可建**沿海城市**，才能造航海协会、训海军）
2. **归属**：该坐标必须是**你自己已占领的野地**（先征服该野地）
3. **空位**：该位置不能已有城市
4. **军衔配额**：可建城数受**军衔限制**（`city_max`），提升声望（军衔晋升）解锁更多城市上限
5. **资源**：消耗粮食/钢铁/石油/稀矿/黄金**各 10 万**（从当前操作城扣除，任一不足无法起新城）

### 2. 新城初始状态
新城自带资源：黄金 2 万、粮/钢/油/稀矿各 5000，并自动初始化市政厅、民居、农田 1 级。初始人口上限 100。

### 3. 城市管理与切换
- 城市列表区分主城/分城，当前操作城有操作按钮，非当前城可**运输/派遣/弃城**
- 切换城市后当前操作的城市即切换（点城市名切换，无弹窗提示）
- **被征服占光所有城市后，系统会补给一座随机新城市保底**（保证永远有城）

### 4. 起分策略
- 沿海位置稀缺，优先占沿海平原野地→建沿海城（海军大本营）
- 分城就近发展资源/分兵驻守，形成多城联防
- 每座分城都要补围墙和城防，避免被一波端

## 五、采集

### 1. 采集玩法
派遣部队到已占领野地进行采集，**每 1 小时一个采集周期**（管理端可配置），每满一个周期结算一期。每满一个采集周期**保底掉落 1 件宝物**，另有 **20% 概率多掉 1 件**；未满一个周期就停止/提前召回则**不给宝物**。

### 2. 采集资源产出（最终数值）
```
F = M × N × R × A ÷ 2
```
- **M（部队总兵力）**：出征部队里**所有兵种数量之和**（原说明以运输卡车举例而已）；不同兵种的差异只体现在**负重**不同，产量贡献一律按数量计
- **N（小时数）**：满一个采集周期的整期结算按**整点小时**（16:59 按 16 小时算，向下取整）；
  **`[停止采集]`/`[一键收获]`/`[召回]` 未满一期的折算按真实时长连续计算，不整点取整**（2026-10-21 用户规则「采集多少就是收获多少」——采 37 分钟就拿 37 分钟的产量；驻守过仍保底 1 点资源）
- **R（野地加成%）**：出发城市名下**与该野地同资源**的所有野地总等级 × 每级加成（默认每级 3%）
  - 例：城市有 10 级森林 + 4 级森林 → 粮食野地加成 = 14 × 3% = **42%**
  - 森林/草原/平原/渔场产粮，丘陵/岛屿产钢，沼泽/海底森林产油，盆地/矿礁产稀矿
- **A（军官后勤）**：带队军官的后勤属性，直接作为乘数（不再折算成 +N% 上限）
- **海野（海底森林 / 岛屿 / 渔场 / 矿礁）产出** = 公式结果 × **海野采集倍率（默认 3）** —— 同参数下海野比陆地野地高 3 倍；陆地野地不乘；玩家端一律不展示倍率，仅管理端本页可见
- 例：180000 兵力 × 16 小时 × 42% × 324 后勤 ÷ 2 = **195955200**
- 产出资源按**地形固定一种**（粮食/钢铁/石油/稀矿），不产黄金
- 资源先存部队**待带回（carry）**，可以超过负重上限（装不下的部分不再直接入城/丢弃，
  2026-10-21 用户规则：**用户点 `[停止采集]`/`[一键收获]` 后才一并进入部队原出发城市**；`[召回]` 则随返航到达入城）；负重满了部队照常继续采，不自动停止
- 管理端「二战系统配置 → 野地与行军」可调：每级野地加成%、公式除数、**海野采集倍率**（原「采集卡车兵种ID」设置已随 M 口径取消）

### 2.1 采集基数速算（怎么估算产量）
- **每级野地加成基数**：城市名下**同资源**野地每 1 级 = +3%（默认，管理端可调）
  —— 例：10 级森林 + 4 级森林 → 粮食加成 42%；野地等级越高块数越多，加成越厚
- **每 1000 兵力、每 1 小时的产量基数 = 5 × R × A**
  （把 M=1000、N=1、÷2 代入公式即得；R=野地加成%数值、A=军官后勤数值，
  兵力和小时数**线性放大**）
- 海野在同基数上再 × 海野倍率（默认 3）

| 场景 | 野地加成 R | 军官后勤 A | 每 1000 兵·每小时 |
|---|---|---|---|
| 1 级野地（3%） | 3 | 100 | 1,500 |
| 5 级野地（15%） | 15 | 100 | 7,500 |
| 10 级野地（30%）+ 后勤200 | 30 | 200 | 30,000 |
| 截图示例：14 级总等级（42%） | 42 | 324 | 68,040 |
| 上例若是海野（×3） | 42 | 324 | 204,120 |

心算示例：18 万兵力 = 180 千兵；180 × 68,040/时 × 16 小时 = **195,955,200**（与上面的例完全对上）。
未满一期的 `[停止采集]`/`[一键收获]`/`[召回]` 用同一基数按真实时长连续折算（不整点取整）。

### 3. 地形与宝物对应
- 草原 / 森林 / 盆地 / 丘陵 / 沼泽 / 岛屿 / 海底森林（terrain 2~8）：各有 3 种采集宝物
- **平原 / 沿海平原（terrain 1/9）：无珠宝**——采集请优先选有宝物的地形

### 3.1 采集宝物建议
宝物是**军衔晋升的必需品**（每种珠宝×N 才能晋升），同时每件三属性+5 可装备。建议**按军衔晋升需求选地形**，不要盲目乱采：

| 采集地形 | 可出珠宝 | 适合 |
|---|---|---|
| **盆地** | 黑曜石、琥珀、铂金 | 前期首选（中士~中尉晋升主力） |
| 森林 | 黑曜石、红宝石 | 黑曜石/红宝石缺口 |
| 丘陵 | 黄金手镯、玛瑙、红宝石 | 上士~上尉晋升 |
| 沼泽 | 琥珀、蓝宝石 | 蓝宝石缺口（少校后） |
| 草原 | 翡翠、祖母绿 | 军士长/少尉晋升 |
| 海底森林 | 翡翠、祖母绿、蓝宝石 | 中后期 3 种兼得 |
| 岛屿 | 红宝石、琥珀、祖母绿 | 红宝石/祖母绿缺口 |

- **前期（中士~上尉）**：死磕**盆地**——同时出黑曜石/琥珀/铂金，覆盖 4~9 级晋升需求
- **中期（少校~大校）**：补采**海底森林/草原**（翡翠/祖母绿）和**沼泽**（蓝宝石）
- **后期（大将~五星上将）**：九种珠宝各要 60~100，按缺口地形轮换采集
- 宝物溢出后不要停：活动野地必掉宝物、宝物签到也能补量

### 4. 操作要点
- **一键收获**：到期后一键收获宝物与资源
- **停止采集**：可主动停止（停止后后端清零采集状态），但未满周期停止不给宝物，建议等满周期再收
- 采集到的宝物直接进背包，自动落到**出发城市**
- 采集中的野地不能被打/被采集（征服/掠夺操作会被拦截）
- 背包宝物上限 5000，达到上限停止给宝物并自动停止采集

### 5. 宝物查看
底部导航「宝物」进入独立宝物页：展示背包内的采集宝物（按名称合并显示"名称×数量"），并提供**去野地采集**、**宝物签到**入口。进入页面自动加载背包宝物数据。

## 六、玩家战争

### 1. 出征与战斗流程
选择目标（玩家城市/野地/寇城）→ 选部队与统帅军官 → 出征。战斗为**回合制**：部队按速度/指令移动，进入射程后开火；射程够不到时"前进"，既移不动又够不到则记录"超出射程无法攻击"。

### 2. 伤害核心公式
```
伤害 = (攻击属性×5 + 1000) / (目标防御×(1+防御加成%)×3 + 10) × 部队数量 × (1+攻击加成%)
（最低伤害 = 数量×5）
```
- **攻击属性按目标兵种选择**：打海军用对海、打陆军用对地、打空军用对空、打城防用 max(对地,对海)
- 攻击加成来源：军官 + 科技 + 装备 + 兵种专属（如狼群战术=海军对海+90%）
- 防御加成来源：城墙 + 科技 + 城守 + 装备 + 兵种专属（掩体只对城防生效）

### 3. 暴击
- 几率 = 装备/套装暴击（封顶 **100%**）
- 命中后伤害 ×(1 + 暴击伤害%)；暴击伤害为 0 时按 **50%** 兜底倍率
- 击杀数向上取整（有余数多杀 1 个），战报有【暴击+X%】标记与播报

### 4. 军官与装备
- 军官在**军校**挑选/培训，**参谋部**任命城守
- 军官分普通/名将，属性（军事/后勤/学识）影响战斗与建设
- 装备/套装提供三维属性 + 六项战斗加成（伤害/防御/生命/移动/暴击/暴击伤害），穿齐套装触发套装额外加成

### 5. 战报与情报
- 战斗报告/军情警讯记录每一场战斗完整战报（含暴击、反击、势不可挡连杀）
- **雷达站**预警敌军入侵，侦察技巧科技提升情报等级，更早看到来袭城市与坐标

### 6. 征服与掠夺（玩家城市，最终数值）
- **掠夺玩家城市**：按对方城市当前资源的一定比例抢走（基础比例受「掠夺技巧」科技每级 +2%、黄金眼技能加成），**掠夺玩家城市不产黄金**（黄金只在打野地/寇城时有）
- **征服玩家城市**：攻破城墙并占领对方城市；玩家被征服占光所有城后，系统补给一座新城市保底
- 防守方城墙/城防/城守/驻军越强，掠夺与征服越难成功

### 7. 攻防策略
- 防守：围墙 + 城防设施（碉堡/榴弹炮/反坦克炮/防空炮）+ 城守军官 + 驻军
- 进攻：侦察后带克制兵种 + 高统帅军官，优先集火对方远程（火箭/榴弹炮）
- 掠夺比例可被「掠夺技巧」科技提升；战后伤兵可被「治愈伤兵」科技恢复

## 九、军团战争

### 1. 军团基础
- 创建/加入军团；军团可开启「入团需审核」模式（申请后由军团长通过/拒绝）
- 军团之间可标记**友好/敌对**外交关系（双向记录），友好与敌对**都可以宣战**

### 2. 宣战与生效
- 军团长宣战后：**12 小时后生效，48 小时整场结束**（生效窗口 = 第 12~48 小时，共 36 小时）
- 生效期间，**双方军团成员之间可互相掠夺/征服，无需个人宣战**
- 结算战绩：
  - 掠夺胜利 → 获胜方军团 +10 战绩，攻击者个人积分 +10
  - 征服胜利 → 获胜方军团 +20 战绩，攻击者个人积分 +20

### 3. 军团积分与商城
- 成员在军团交战期获胜累加**个人军团积分**（战绩）
- 个人积分可在**军团商城**兑换商品（货币 = 个人军团积分）

### 4. 盟军驻军
- **联络中心**允许盟友驻军，可派增援部队驻守盟友城市
- 盟军驻军战「溃败撤退」：守方剩余兵力跌破初始兵力的 **50%** 即判定战败，战斗提前结束，剩余部队自动**返航回出发城市**——驻军战败有兵可回，不会白白全灭

### 5. 军团战建议
- 开战时先确认敌对军团成员坐标，抱团集中打高价值目标（对方主城/资源城）
- 掠夺（+10）性价比高，适合消耗战；征服（+20）用于终结对手
- 防守方记得让盟友驻军（联络中心），多一队守军就多一分胜算
